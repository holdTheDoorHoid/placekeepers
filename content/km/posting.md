# កន្លែង​បិទ​ខិត្តប័ណ្ណ

ខិត្តប័ណ្ណ​នៅ​លើ​របង​នៃ​ដី​ទំនេរ​មួយ​ប្រាប់​អ្នកដើរ​កាត់​ថា​អ្នកជិតខាង​យកចិត្ត​ទុកដាក់​ចំពោះ​កន្លែង​នោះ និង​របៀប​រកគ្នា។ Placekeepers អាចប​ង្កើត​មួយ​សម្រាប់​ដី​ឡូត៍​ណាមួយ៖ បើក​ទំព័រ​របស់​ដី​ឡូត៍ ហើយ​ជ្រើសរើស "បង្កើត​ខិត្តប័ណ្ណ​សម្រាប់​អ្នកជិតខាង"។ ទំព័រ​នេះ​គឺ​អំពី​កន្លែង​ដែល​អ្នក​អាច​បិទ​វា​បាន ដោយ​ចាប់ផ្តើម​ពី​កន្លែង​ស្របច្បាប់​មុនគេ។

នេះ​មិនមែន​ជា​ដំបូន្មាន​ផ្នែក​ច្បាប់​ទេ។ យើងខ្ញុំ​បាន​ពិនិត្យ​ច្បាប់​ខាងក្រោម​ចុងក្រោយ​នៅ​ថ្ងៃទី 21 ខែតុលា ឆ្នាំ 2026។ ច្បាប់​ផ្លាស់​ប្តូរ ដូច្នេះ​សូម​ពិនិត្យ​ជាមួយ​ទីក្រុង បើ​អ្នក​មិន​ប្រាកដ។

## កន្លែង​ល្អ​ដើម្បី​បិទ

- **បង្អួច ទ្វារ ឬ​របង​ផ្ទាល់ខ្លួន​របស់​អ្នក។** ទ្រព្យសម្បត្តិ​ផ្ទាល់ខ្លួន​របស់​អ្នក​គឺជា​របស់​អ្នក​ក្នុង​ការ​បិទ។ ខិត្តប័ណ្ណ​នៅ​ខាងក្នុង​បង្អួច​របស់​អាជីវកម្ម​មួយ​រាប់​ចូលក្នុង​ដែន​កំណត់​របស់​ទីក្រុង​លើ​ផ្ទាំង​បង្អួច (ផ្ទាំង​អាច​គ្រប​ដណ្តប់​មិន​លើស​ពី 20 ភាគរយ​នៃ​កញ្ចក់​ដោយ​គ្មាន​លិខិតអនុញ្ញាត) ដូច្នេះ​ខិត្តប័ណ្ណ​តែមួយ​គឺ​មិន​អី​ទេ។
- **របង​របស់​ម្ចាស់ដី​ឡូត៍ ដោយមាន​ការអនុញ្ញាត។** សូម​សួរ​ជាមុន។ បើ​ម្ចាស់​យល់ព្រម សូម​កត់ត្រា​ថា​ពេលណា និង​របៀប​ដែល​គាត់​បាន​យល់ព្រម។ ទំព័រ​របស់​ដី​ឡូត៍​ដាក់ឈ្មោះ​ម្ចាស់​ដូចដែល​ទីក្រុង​ផ្សព្វផ្សាយ ហើយ​ទំព័រ​លិខិត​មាន​លិខិត​មួយ​សុំ​ការអនុញ្ញាត​ពី​ម្ចាស់​ដើម្បី​ថែរក្សា​ដី​ឡូត៍។
- **ក្តារ​បិទផ្សាយ​សហគមន៍​នៅ​បណ្ណាល័យ និង​មជ្ឈមណ្ឌល​កម្សាន្ត។** សូម​សួរ​បុគ្គលិក​មុន​ពេល​អ្នក​បិទ។ Free Library រាយ​ការ​បិទ​សម្ភារៈ​ដោយ​គ្មាន​ការ​អនុម័ត​ជាមុន​ថា​ជា​ការ​រំខាន ហើយ Parks and Recreation អនុញ្ញាត​ឱ្យ​មាន​ក្តារ​ផ្សាយ និង​ក្តារ​ជូនដំណឹង​នៅ​ទីតាំង​របស់​វា។ បុគ្គលិក​នឹង​ប្រាប់​អ្នក​ថា​នៅកន្លែង​ណា និង​យូរប៉ុណ្ណា។
- **អាជីវកម្ម​ដែល​យល់ព្រម។** ហាង​ជ្រុង ហាង​បោកខោអាវ ហាងកាត់សក់ និង​ហាង​កាហ្វេ​ច្រើនតែ​មាន​ក្តារ ឬ​បង្អួច។ សូម​សួរ​ម្ចាស់ ឬ​អ្នកគ្រប់គ្រង។
- **ប្រគល់​ឱ្យ​មនុស្ស។** ការ​ប្រគល់​ខិត្តប័ណ្ណ​ដល់​អ្នក​ដែល​ចង់បាន​គឺ​ត្រូវ​បាន​អនុញ្ញាត។ កុំ​ទុក​ខិត្តប័ណ្ណ​លើ​កញ្ចក់​ខាងមុខ​រថយន្ត ឬ​រាយប៉ាយ​វា ហើយ​រំលង​ទ្វារ​ណា​ដែល​មាន​បិទ​ថា "no flyers" (គ្មាន​ខិត្តប័ណ្ណ)។

## កន្លែង​ដែល​ហាមឃាត់

- **បង្គោល​អគ្គិសនី ភ្លើង​ផ្លូវ ផ្ទាំង​សញ្ញា​ចរាចរណ៍ និង​ផ្ទាំង​សញ្ញា​ចត​រថយន្ត និង​បង្គោល​របស់​វា ផ្ទាំង​សម្គាល់​ប្រវត្តិសាស្ត្រ និង​ដើមឈើ​របស់​ទីក្រុង ឬ​ដើមឈើ​តាមផ្លូវ។** Philadelphia Code section 10-1202 ហាម​បិទ​ផ្ទាំង​លើ​អ្វីៗ​ទាំងនោះ។ ទីក្រុង​ពិន័យ $300 ក្នុង​មួយ​ផ្ទាំង​សម្រាប់​ការប្រព្រឹត្ត​លើកដំបូង និង​រហូតដល់ $2,000 ក្នុង​មួយ​ផ្ទាំង​បន្ទាប់ពី​នោះ (section 10-1203៖ ទីក្រុង​បាន​ប្រកាស​ចំនួន​ទាំងនេះ​ម្តង​ទៀត​ក្នុង​ឆ្នាំ 2018) ហើយ​គិតថ្លៃ​ដក​វា​ចេញ។ ការ​ដំដែកគោល ឬ​ដាក់​អ្វីមួយ​លើ​បង្គោល​អគ្គិសនី​ក៏​ជា summary offense (បទល្មើស​ស្រាល) ក្រោម​ច្បាប់ Pennsylvania ដែរ។
- **ដើមឈើ។** ច្បាប់​របស់ Parks and Recreation ហាម​ភ្ជាប់​ផ្ទាំង​ណាមួយ​លើ​ដើមឈើ​តាមផ្លូវ របាំង​ការពារ ឬ​គ្រឿង​ទ្រទ្រង់​របស់​វា ឬ​លើ​ដើមឈើ​ក្នុង​សួន ដោយមាន​ទោសពិន័យ​យ៉ាងតិច $300 ក្នុង​មួយថ្ងៃ។
- **កញ្ចក់​ខាងមុខ​រថយន្ត និង​ខាងក្នុង​រថយន្ត។** Philadelphia Code sections 10-711 និង 10-723.2 ហាម​ដាក់​ខិត្តប័ណ្ណ (handbills) លើ ឬ​ក្នុង​យានយន្ត៖ សេចក្តី​ជូនដំណឹង​អំពី​ការបំពាន​គឺ $100។
- **ប្រអប់​សំបុត្រ។** ច្បាប់​សហព័ន្ធ​ហាម​ដាក់​អ្វីមួយ​ដោយ​គ្មាន​តែម​ប្រៃសណីយ៍​ក្នុង​ប្រអប់​សំបុត្រ។
- **ជម្រក ស្ថានី និង​យានយន្ត​របស់ SEPTA។** យើងខ្ញុំ​រក​មិនឃើញ​ច្បាប់​របស់ SEPTA ដែល​អនុញ្ញាត​ឱ្យ​បិទ​លើ​ទ្រព្យសម្បត្តិ​របស់​វា​ទេ ដូច្នេះ​សូម​ចាត់ទុកថា​ហាមឃាត់ ហើយ​សួរ SEPTA ជា​លាយលក្ខណ៍​អក្សរ​ជាមុន។

## មុន​ពេល​អ្នក​បោះពុម្ព

- **អ្វី​ដែល​អ្នក​បោះពុម្ព​គឺ​សាធារណៈ។** អ្នកណា​ក៏អាច​អាន និង​ថតរូប​ខិត្តប័ណ្ណ​មួយ​បាន។ សូម​ប្រើ​តំណ​ភ្ជាប់​ក្រុម​ជជែក ឬ​អាសយដ្ឋាន​អ៊ីមែល​ដាច់ដោយឡែក​ដែល​បង្កើត​សម្រាប់​គម្រោង ជំនួស​ឱ្យ​អាសយដ្ឋាន​ផ្ទះ ឬ​លេខទូរស័ព្ទ​ផ្ទាល់ខ្លួន។
- សូម​ដាក់​កាលបរិច្ឆេទ​លើ​វា ហើយ​ដក​វា​ចេញ​នៅពេល​វា​ហួសសម័យ។
- កូដ QR របស់​ខិត្តប័ណ្ណ​បើក​ទំព័រ​របស់​ដី​ឡូត៍​នៅ​លើ Placekeepers។ វា​មិន​មាន​អ្វី​ដែល​តាមដាន​ថា​អ្នកណា​បាន​ស្កេន​ទេ។
