# Khmer glossary (km)

The words chosen for Placekeepers in Khmer, so the interface, the registry text and the content
pages say the same thing the same way. English is the source. Written by the translating agent,
not yet checked by a native speaker: every row is a proposal for the native reviewer to confirm
or change.

## Style

- Standard written Khmer, plain and polite. "អ្នក" for "you". "យើងខ្ញុំ" for "we" (polite).
  Requests start with "សូម".
- Sentences end with the Khmer full stop "។". The Khmer colon "៖" is used where English uses a
  colon. Commas are used sparingly (Khmer separates phrases with spaces); there is no comma at all
  in the notes that go at the top of a CSV file, as in English.
- No dashes as punctuation. Digits stay Western (0 to 9), as the site formats them. Ranges are
  written "ពី 2019 ដល់ 2024".
- A zero width space (U+200B) sits between words, added by running every Khmer run through the
  ICU Khmer word segmenter (`Intl.Segmenter('km')`), so lines break between words. The repetition
  mark "ៗ" stays attached to its word. The Khmer files in the repository carry the spaces; to
  edit one, take a copy with them removed (every U+200B), edit, then add them again the same way.
- Latin script is kept for proper names and for words a neighbor will see in English on the
  City's own pages (see "Names that stay in English"). A Khmer gloss in brackets goes beside a
  legal or technical English word where a neighbor may need to say it to a lawyer or an office
  (conservatorship, adverse possession, redlining, brownfield, zoning).

## What the City itself writes in Khmer (phila.gov, the "I speak" card of 2021)

- City of Philadelphia: "ទីក្រុង Philadelphia" (the English name stays in Latin script). So the
  site writes "Philadelphia" in Latin script everywhere.
- City agency: "ទីភ្នាក់ងារក្នុងក្រុង"; City government: "រដ្ឋាភិបាលទីក្រុង"; services:
  "សេវាកម្ម"; information: "ព័ត៌មាន"; residents: "ពលរដ្ឋ"; free: "ដោយឥតគិតថ្លៃ"; immigrant:
  "អន្តោប្រវេសន៍".
- phila.gov publishes no Khmer names for L&I, Philly311, the Land Bank, PHDC, the Redevelopment
  Authority or their programs, so those stay in English.

## Lenses and badges

Lens names: ការកាត់បន្ថយអំពើហិង្សា (violence reduction), កម្តៅ និងម្លប់ (heat and shade),
ការធ្វើឱ្យកន្លែងមានជីវិត (placemaking), សុវត្ថិភាពផ្លូវ (street safety), ភាពស្រួលនៃការដឹកជញ្ជូន
សាធារណៈ (transit comfort).

Evidence badges: ភស្តុតាងរឹងមាំ (strong), ភស្តុតាងមធ្យម (moderate), ភស្តុតាងចម្រុះ (mixed),
ភស្តុតាងខ្សោយ (weak), មិនទាក់ទងនឹងអំពើហិង្សា (not about violence), បរិបទ (context).

## Catch up pass (2026-10-22)

Changed by the orchestrator's instruction, after the checker's note above: "listed as available"
now reads as the City's own status label, not as "you can ask for it". The Khmer is
ចុះបញ្ជីថា “អាចរកបាន” (listed as “available”), with the word in curly quotes so it reads as the
City's label, and "not available" is មិន “អាចរកបាន”. "អាចសុំបាន" (can be asked for) is no longer
used for this. The Land Bank's own rule that it may still say no stays beside it
